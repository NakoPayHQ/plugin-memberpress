Accept Bitcoin and crypto payments for MemberPress memberships via NakoPay.

== Description ==

NakoPay for MemberPress adds Bitcoin and cryptocurrency payments to your
membership site. Non-custodial, wallet-to-wallet settlement with a flat 1% fee.

= Features =

* Hosted checkout - members pay on a NakoPay-hosted page with QR code
* HMAC-SHA256 webhook verification
* Automatic membership activation
* Test mode for development

== Installation ==

1. Upload the plugin zip via Plugins > Add New > Upload Plugin
2. Activate the plugin
3. Go to MemberPress > Settings > Payments and add NakoPay as a gateway
4. Enter your API key and webhook secret
5. Set the webhook URL in your NakoPay dashboard
